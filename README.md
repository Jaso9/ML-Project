#

Был проведен разведочный анализ данных, выявлены закономерности.

Использованы кастомные трансформеры для обработки тренировочных и тестовых данных.

Реализованы 4 базовые модели:
* Random Forest
* XGBoost
* LightGBM
* CatBoost

Несколько лучших моделей отправлялись на тест в соревнование, результаты прилагаются в коде.

Затем был реализован подбор гиперпараметров для каждой модели с [Optuna](https://optuna.org/).

В работе была использована кросс-валидация через [StratifiedKFold](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.StratifiedKFold.html).

Был реализован стекинг на основе 4 моделей с лучшими параметрами и мета-модели логистической регрессии.

По итогу работы в директории *Output* будет 6 файлов с предсказаниями тестовой выборки, они названы в соответствии с решающей моделью.

#

CatBoost показывал отличные результаты со стандартными параметрами, модель стекинга ошиблась на 0,00046. С учётом размеров выборок это различие примерно в одного пассажира.

XGBoost и Random Forest показали результаты хуже, чем LGBM и Catboost. У XGBoost ответ попадает примерно в топ 700, у двух лучших - примерно в топ 300.

Также подбор гиперпараметров с Optuna вызывал затруднения при обучении LGBM. Попытки были слишком долгими, в районе 5-10 минут за каждую. 
Решением было ввести subsamle-гиперпараметры. Они позволяли не анализировать датасет полностью, а проходиться по какой-то части, что сильно экономило время.

На сложные операции были поставлены таймеры для контроля времени и возможной оптимизации.
