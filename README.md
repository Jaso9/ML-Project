# Machine Learning Project

## Prediction price of used car
ML-проект по решению задачи предсказания цены использованного автомобиля на основе сопутствующих признаков.
В качестве данных используется датасет с **[Kaggle](https://www.kaggle.com/)**: **[Used Car Price Prediction Dataset](https://www.kaggle.com/datasets/taeefnajib/used-car-price-prediction-dataset/data)**. Целевой переменной считается `price` (цена автомобиля).


Из представленных данных можно извлечь особые показатели автомобилей, протестировать их влияние на предсказания моделей, видоизменить некоторые данные, проанализировать прогнозы моделей на их основе.

## Гипотезы

**1:** Между пробегом автомобиля и его ценой (колонки `milage` и `price` соответственно) существует отрицательная корреляция.

**Проверка:** Построить диаграмму рассеяния для двух признаков и посмотреть на получившийся график с линией тренда.

**Итог:** Подтвердилась, хотя выбросы могут приближать линию тренда к горизонтальной.
<br>
<br>    
**2:** Наличие чистого ПТС (колонка `clean_title`) влияет на цену автомобиля, есть положительная корреляция.

**Проверка:** Закодировать признак на этапе разведочного анализа и проанализировать тепловую карту.

**Итог:** Не подтвердилась. Наличие чистого ПТС не оказывает влияния на цену.
<br>
<br>
<br>
**3:** Показатель $R^2$ будет лучше, если заменить год производства автомобиля на его возраст. Возможно, начало отсчёта с 0 позволит модели улучшить показатели точности, в отличие от работы с годичной временной шкалой.

**Проверка:** Построить два пайплайна, один будет содержать столбцы с возрастом, другой - с годом производства. Сравнить критерий $R^2$ в двух случаях.

**Итог:** Не подтвердилась. Оба столбца линейны, возраст считался вычитанием года производства из текущего года.
<br>
<br>
<br>
**4:** Логарифмирование таргета улучшит метрику $R^2$ линейной регрессии.

**Проверка:** Построить два пайплайна: один без логарифмирования таргета, другой - с логарифмированием (с использованием `TransformedTargetRegressor`) и оценить $R^2$.

**Итог:** Подтвердилась, коэффициент детерминации возрос.
<br>
<br>
<br>
**5:** Нахождение лучших параметров с использованием GridSearch даст прирост в метрике $R^2$ по сравнению с базовыми настройками модели.

**Проверка:** Обучение модели на стандартных настройках, затем подбор параметров. Сравнение метрик моделей.

**Итог:** Подтвердилась, модель с найденными параметрами отработала на тренировочных данных лучше.
